# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop built with React and Redux Toolkit.

## Features

- A landing page with the company name, a background image, and a "Get Started" button
- A product listing page with houseplants grouped into categories
- "Add to Cart" buttons that add a plant to the cart and disable themselves once added
- A navigation bar with links to Home, Plants, and Cart
- A cart icon that shows the total number of items
- A shopping cart page with quantity controls, per-plant totals, a total cart amount, and a delete button
- A checkout button that shows a "Coming Soon" message and a Continue Shopping button

## Tech Stack

- React
- Redux Toolkit
- CSS

## Getting Started

    npm install
    npm run dev
